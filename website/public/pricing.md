# Pricing — Dripwriter Origin

Dripwriter Origin is free. There is a single tier.

## Free
- Price: $0 — free forever for all noncommercial use
- Account: none required. No login, no sign-up, no OAuth, no permission paper trail.
- Data: no telemetry and no external servers. Everything runs locally in your browser.
- Features: the full humanized typing engine — adjustable speed (20–150 WPM) with variance, keyboard-neighbor typos that auto-correct, deleted false starts, and configurable breaks. Works on Google Docs, Canvas, the Packback editor, and virtually any textarea or contenteditable field on any website. Optional developer/AI API (`window._dripwriter`).
- Browsers: Chrome, Microsoft Edge, Firefox
- Install: https://extension.dripwriter.org

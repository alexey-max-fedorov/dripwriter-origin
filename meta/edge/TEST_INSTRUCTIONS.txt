TESTING INSTRUCTIONS — Dripwriter Origin

IMPORTANT — READ FIRST
This extension types where YOUR CURSOR is in the active text box — a Google Doc,
a Canvas assignment, or any standard textarea or contenteditable field. You MUST
click inside that field first to place the text cursor. Skip this and there is no
cursor to type into, so nothing appears. This is the #1 reason testing looks like
it "does nothing." The steps below use Google Docs as the primary example because
it has the most finely tuned typing engine.

PREREQUISITES
- Microsoft Edge with the extension installed
- A free Google account
- A Google Docs document open in Edge (the primary test target; any page with a
  text box also works)

SETUP
1. Open a doc: https://docs.google.com/document/create
2. Click the Dripwriter Origin toolbar icon to open the popup.
3. Paste any text (a sentence or two) into the popup text area.

CORE FLOW
4. *** REQUIRED *** Click directly inside the Google Docs document body where
   you want typing to begin. You should see the blinking text cursor. Without
   this, the extension has no cursor to type into and appears to do nothing.
5. Click the toolbar icon again to reopen the popup, then click Start.
6. After a 3-second countdown, the extension types the text character by
   character at a natural, variable pace.
7. Click Stop at any time to halt typing.

If nothing types, return to step 4 — the cursor was not placed. Click into the
document body, reopen the popup, Start.

SETTINGS
8. Adjust Typing Speed, Typo Rate, or False Start Rate via the sliders.
9. Click Start again — new settings take effect. Reopen popup to confirm they
   persisted.

DIAGNOSTICS
10. Click inside the document body, open the popup, click Diagnostics. Confirm
    it completes and inserts marker text, reporting the input area reachable.

CROSS-SITE CHECK
11. Open any page with a plain text box (e.g. a Canvas assignment, or a site
    with a textarea). Click into the field, open the popup, paste text, Start —
    confirm it types there too.

BOUNDARY CHECK
12. Go to a browser-internal page where no content script can run (e.g.
    edge://newtab). Open the popup — confirm it indicates it is inactive on this
    page.

PERMISSIONS
storage (saves settings locally), tabs (identifies active tab), and host access
to all sites (injects the typing script into whatever page you're typing into).
No external network requests.

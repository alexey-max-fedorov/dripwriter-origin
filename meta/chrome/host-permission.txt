Host access to all sites (<all_urls>) is required because Dripwriter Origin types the user's text into whatever editable field they are working in, and that field can be on any website — a Google Doc, a learning-management system such as Canvas, an embedded third-party editor (for example the Packback editor that loads inside an LTI iframe), or any standard textarea or contenteditable field on any page. The content script is injected only to dispatch keystroke events into the field the user has clicked into on the page they are actively viewing. Injection runs in all frames because many editors live inside embedded cross-origin iframes and cannot be reached otherwise. The extension never reads, stores, or transmits page content, never accesses browsing history, and only ever types into the single field the user targets. No page data is collected or sent to any external server.

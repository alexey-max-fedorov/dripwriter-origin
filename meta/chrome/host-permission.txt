Host permission for https://docs.google.com/* is required to inject the content script into Google Docs pages. The content script handles all keystroke simulation — it receives the user's text and typing settings from the popup and dispatches keyboard events into the document's active input element. Without this permission, the extension cannot attach to the page and typing cannot occur. The permission is scoped exclusively to docs.google.com; the extension requests no access to any other domain. No Google Docs content is read, stored, or transmitted by the extension at any point.

The scripting permission is required to inject a content script into the MAIN world of Google Docs pages. Dripwriter Origin includes a bridge script that must run in the page's main JavaScript execution context — not the default isolated content script sandbox — in order to expose window._dripwriter to external JavaScript.

This API enables Dripwriter Origin's developer and AI integration feature. Scripts in the browser console or AI agent tool-use flows can call window._dripwriter.start(), .stop(), .status(), and .test() to control typing sessions programmatically. Because window is not shared between the MAIN world and the isolated world in Chrome MV3, the bridge must execute in the MAIN world to attach to the page's global scope.

No arbitrary code injection occurs. The bridge script is bundled with the extension, fixed at install time, and only activates on https://docs.google.com/document/* pages. It does not read page content, access user data, or communicate with any external server.

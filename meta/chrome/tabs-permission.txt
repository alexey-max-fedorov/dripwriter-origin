The tabs permission is used for two specific purposes required for the extension's core function. First, it queries the currently active tab to read its URL and confirm it is a Google Docs document (matching https://docs.google.com/document/*) before any action is taken — this prevents the extension from operating on unintended pages. Second, it sends messages to the content script running in that tab (via chrome.tabs.sendMessage) to start, stop, or query the status of a typing session. The extension never reads tab content, never accesses browsing history, and only ever interacts with the single currently focused tab in the active window. No tab data is stored or transmitted externally.

The storage permission is used exclusively to persist the user's typing configuration and UI theme preference in Chrome's local storage on the user's own device. Stored data includes: typing speed (WPM), speed variance, typo rate, false-start rate, break frequency, break duration range, and dark/light theme selection. These settings are restored each time the popup is opened so users do not need to reconfigure on every use. A session flag is also stored per browser tab to control the popup's animated title — it plays once per tab session and never again. No user text, document content, or personally identifiable information is ever stored. All data remains on the local device and is never transmitted to any external server or service.
